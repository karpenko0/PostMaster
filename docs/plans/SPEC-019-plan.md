# План разработки SPEC-019 «Команда `/help`»

- Спецификация: [docs/specs/SPEC-019.md](../specs/SPEC-019.md)
- Статус: ✅ реализовано и проверено (472 теста пройдены; проверка минимальной версии Python исключена из-за Python 3.11 в sandbox)

## 1. Решения

| № | Решение | Причина |
|---|---|---|
| D1 | Справку хранить в константе `HELP_TEXT` в handler | Текст статичен, БД и отдельный сервис не нужны |
| D2 | Регистрировать команду до generic text handler | `/help` должен обрабатываться как команда в любом состоянии FSM, а не как дата/сообщение сценария |
| D3 | Handler не вызывает `DialogService`, не читает/не пишет FSM, DB или Scheduler | Обеспечить preservation state/data и отсутствие побочных эффектов |
| D4 | Ошибку Telegram send логировать только Telegram ID и тип исключения | Не раскрывать детали API/токена; состояние FSM остаётся неизменным |
| D5 | Указывать оба режима публикации в общей справке | Пользователь понимает вариант Reminder и автоматическую публикацию канала без настройки runtime-сервиса |
