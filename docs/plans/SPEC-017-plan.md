# План разработки SPEC-017 «Команда `/my_posts`»

- Спецификация: [docs/specs/SPEC-017.md](../specs/SPEC-017.md)
- Статус: ✅ реализовано и проверено (447 тестов пройдены; smoke-проверка версии Python исключена из-за Python 3.11 в sandbox)

## 1. Цель

Добавить пользовательский read-only сценарий списка ожидающих публикаций с изоляцией по владельцу на уровне SQL, отображением локального времени и понятной обработкой ошибок.

## 2. Решения

| № | Решение | Причина |
|---|---|---|
| D1 | Выделить `PostQueryService`, который находит пользователя по Telegram ID и вызывает `list_pending_by_user(user.id)` | Handler не работает с repository напрямую; при отсутствии User посты не запрашиваются |
| D2 | Фильтр `user_id` + `status=PENDING` оставить внутри `PostRepository` | Обеспечить изоляцию данных на уровне запроса, как требует §12 |
| D3 | Форматировать дату через `convert_utc_to_local(post.scheduled_at_utc, post.timezone)` | У поста хранится использованный при планировании timezone |
| D4 | Показывать ID, дату/время и локализованный тип; caption не выводить | Компактный формат и минимизация ненужного содержимого |
| D5 | Делить длинный список на сообщения ниже Telegram-лимита | Сохранить работу для большого количества публикаций |
| D6 | При ошибках логировать только идентификатор и тип исключения, пользователю показывать нейтральный текст | Не раскрывать детали БД/исключений |
